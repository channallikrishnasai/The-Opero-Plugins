# The-Opero-Plugins

Community plugins for [**The Opero**](https://github.com/channallikrishnasai/The-Opero) — drop-in Python modules that extend the assistant without touching its core.

## Install

Copy the plugin file(s) you want into the `plugins/` folder of your Opero install and restart. Files starting with `_` are helpers, not standalone plugins — they are imported by the plugin that needs them and must sit in the same folder.

Some plugins need extra packages (`pip install …`) or an API key; each file's docstring says exactly what it needs and fails with a plain-English message when something is missing.

## Plugins

| Plugin | What it does |
|---|---|
| [`telegram_remote.py`](plugins/telegram_remote.py) | Drive Opero from your phone over Telegram — no inbound port, allowlist + pairing code + rate limits built in. Companion: [`_telegram_ops.py`](plugins/_telegram_ops.py) (screen capture, hardware readout, files, voice, undo — keep both files together). |
| [`chat_takeover.py`](plugins/chat_takeover.py) | Watches a chat open on screen and auto-replies in your texting style via vision + Gemini Live. Stop by voice, mouse-in-corner, or timeout. |
| [`excel_writer.py`](plugins/excel_writer.py) | Spoken request → real `.xlsx` on your Desktop (headers, totals, optional chart). Needs `openpyxl`. |
| [`document_review.py`](plugins/document_review.py) | Lays out a contract/policy/letter on screen: what it is, what signing commits you to, points ordered by severity. No legal knowledge baked in — the model reads, this plugin presents. |
| [`pomodoro.py`](plugins/pomodoro.py) | Background Pomodoro timer that speaks phase changes and remembers today's focus across sessions. |
| [`quiz.py`](plugins/quiz.py) | On-screen quiz generated by the model; answers come back as a `[QUIZ_DONE]` message for marking. Keeps no store of its own. |
| [`water_reminder.py`](plugins/water_reminder.py) | Spoken hydration reminders + daily intake tracking with a rolling memory note. |
| [`calorie_counter.py`](plugins/calorie_counter.py) | Hold food up to the webcam — animated scan, Gemini nutrition breakdown, spoken summary. Needs OpenCV. |
| [`password_generator.py`](plugins/password_generator.py) | Cryptographically strong passwords and memorable passphrases (`secrets`), with a strength rating. Shown on screen only — never logged or spoken. |
| [`disk_analyzer.py`](plugins/disk_analyzer.py) | What's eating the disk: biggest folders, largest files, free space. Measures and lists — never deletes. |
| [`journal.py`](plugins/journal.py) | Spoken daily diary in `memory/journal.jsonl` — write, read by day, or search across entries. |
| [`unit_converter.py`](plugins/unit_converter.py) | Exact unit math (length, mass, temperature, volume, speed, data…) so the model never does the arithmetic itself. No currencies — rates need live data. |
| [`expense_tracker.py`](plugins/expense_tracker.py) | Spoken expense ledger with day/month totals, category breakdown, undo, and a settable currency label. |

## Writing a plugin

Every plugin exposes a `PLUGIN` dict (name, description, JSON parameters) and a `run(parameters, player=None, session_memory=None) -> str` entry point. The description is what the model reads to decide when to call the tool — write it in English, mention trigger phrases, and say what *not* to use it for when that matters. `run` returns one sentence for the user; heavy imports go inside functions so plugin discovery stays cheap.
